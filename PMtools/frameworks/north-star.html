North Star Framework

Align the whole team behind one metric that captures the core value your product delivers.

When to use

  • Aligning a growing team
  • Connecting daily work to value

When not to use

  • As a vanity number with no input metrics

Inputs

  • Candidate value metric
  • 3–5 input metrics teams can move

Steps

  • Pick a metric that reflects delivered value
  • Decompose into inputs
  • Assign inputs to teams
  • Review weekly

Outputs

  • A North Star + input metric tree

Common mistakes

  • Choosing revenue (a result, not value)
  • No guardrail metrics

Example

Spotify: time spent listening; inputs = activation, sessions/user, session length.
